##  Deployment

### Quick Deployment Steps

1. **Set Environment Variables** on your deployment platform:
   ```env
   VITE_API_URL=https://your-backend-api-url.com
   VITE_GEMINI_API_KEY=your_gemini_api_key_here
   VITE_SUMMARIZER_API_URL=https://summarizer-model.onrender.com
````

2. **Build the Application**:

   ```bash
   npm run build
   ```

3. **Deploy to Your Platform**:
   - **Vercel**: `vercel` or connect via GitHub
   - **Netlify**: `netlify deploy --prod` or connect via GitHub
   - **Other platforms**: Upload the `dist` folder

### Important Notes

⚠️ **The recommendation feature requires a deployed backend API**

- Set `VITE_API_URL` to your backend URL (not localhost)
- The app includes fallback mode for demo purposes
- See [DEPLOYMENT.md](DEPLOYMENT.md) for detailed instructions

### Fallback Mode

If the backend API is unavailable, the app automatically switches to:

- ✅ Demo mode with sample data
- ✅ Maintains full UI functionality
- ℹ️ Shows a notice indicating demo mode

For production, ensure your backend API is properly deployed and accessible.

See the **[Deployment Guide](DEPLOYMENT.md)** for comprehensive instructions.

## Troubleshooting Deployment

### Recommendations Not Working?

1. **Check API URL**: Verify `VITE_API_URL` points to your deployed backend
2. **Check Console**: Open browser DevTools (F12) and look for API errors
3. **Test Backend**: Visit `https://your-api-url.com/health` to verify it's running
4. **Rebuild**: After changing environment variables, rebuild and redeploy

See [DEPLOYMENT.md](DEPLOYMENT.md) for detailed troubleshooting steps.
